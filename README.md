## Image revisions

Use image revision tags such as `wodby/mkdocs:rN` to select a Wodby image revision.
See [release tags](https://github.com/wodby/mkdocs/tags) for available revisions and the [image revision policy](https://github.com/wodby/images#image-revisions) for upgrade guidance.
Existing SemVer image tags remain available.
